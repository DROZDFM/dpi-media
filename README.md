# DPI Media

![DPI Media icon](Assets/DpiMedia.png)

Небольшая нативная утилита для Windows 11, которая управляет медиаплеером или сайтом, активным в Windows, если он поддерживает системные медиаклавиши. Для средней кнопки колеса доступны жесты: короткое нажатие — следующий трек, двойное нажатие (в течение 0,3 секунды) — предыдущий трек, удержание — пауза или воспроизведение. Для остальных кнопок доступно воспроизведение и пауза.

## Требования

- Windows 10/11 x64
- .NET 8 Desktop Runtime

## Как пользоваться

1. Запустите DpiMusicControl.exe.
2. Нажмите «Определить» и затем кнопку колесика мыши.
3. Если приложение её увидело, оно автоматически назначит кнопку.
4. Закройте окно — оно скроется, приложение продолжит работать в системном трее. Двойной щелчок по значку снова откроет окно; в меню значка можно включить или выключить сопоставление либо полностью выйти.

У приложения есть собственная фиолетовая иконка мыши с символом воспроизведения, она показывается в окне и системном трее.

## Если DPI-кнопка не определяется (так же можно биндить кнопку dpi если у вас мыши от RAZOR и т.п которые поддерживают это)

Некоторые мыши меняют DPI непосредственно в прошивке, поэтому Windows не получает сигнал. Если у мыши есть фирменная утилита с переназначением, задайте DPI-кнопке одну из свободных клавиш F13–F24 (предпочтительно F13) или Mouse 4 / Mouse 5. Затем в DPI Media снова нажмите «Определить».

У некоторых бюджетных моделей, включая HP S1000 Plus, DPI-кнопка аппаратная и не программируется. Для таких мышей выберите клик колёсика или другую кнопку, которую Windows видит. На средней кнопке короткое нажатие переключает на следующий трек, двойное — на предыдущий, а удержание отправляет команду паузы/воспроизведения.

Настройки сохраняются в %LocalAppData%\DpiMusicControl\settings.json. Включённый автозапуск добавляется только для текущего пользователя Windows.

## Сборка из исходников

Установите .NET 8 SDK, затем из папки проекта выполните:

```powershell
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained false
```

Приложение использует WPF и Windows API, сторонние пакеты NuGet не требуются.
